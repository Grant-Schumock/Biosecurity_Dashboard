# Local Data

This folder is for local data pulled by the dashboard or development scripts.

- `raw/` - unmodified source responses.
- `interim/` - partially cleaned or joined data.
- `processed/` - dashboard-ready datasets, including `legislation.sqlite`.
- `cache/` - temporary files that can be regenerated.

Most contents of this folder are ignored by git. Keep only documentation and `.gitkeep` placeholders tracked.
